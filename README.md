# Password Toolkit

A command-line tool to generate secure random passwords and check password strength.

## Features
- Generate passwords of any length using letters, digits and symbols
- Strength rating from Very Weak to Very Strong
- Uses the `secrets` module for secure randomness

## Technologies
Python, `secrets`, `re`

## How to Run
```bash
python main.py
```

## Sample Output
```
1) Generate  2) Check strength  3) Exit: 1
Length: 12
Password: k#9Lm@2vQx!p | Very Strong
```
